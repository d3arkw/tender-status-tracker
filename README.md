# Tender Status Tracker

Backend-сервис для отслеживания статусов тендеров.

## Стек

- Python / FastAPI
- PostgreSQL
- SQLAlchemy 2.0 + Alembic
- Redis
- Docker / Docker Compose
- GitHub Actions (CI)

## Возможности

- Создание тендера
- Обновление статуса: Черновик → Активен → Выигран / Проигран
- Логирование каждого изменения статуса (кто, когда, почему) в таблицу истории
